HORIZONS AND CLASS LABEL POLICY
Forward return formula: AdjClose[t+h] / AdjClose[t] - 1, where h is the number of subsequent rows for the same symbol.
1-day UP/DOWN/HOLD thresholds: UP if return > +0.50%; DOWN if return < -0.50%; otherwise HOLD.
5-day UP/DOWN/HOLD thresholds: UP if return > +1.00%; DOWN if return < -1.00%; otherwise HOLD.
20-day UP/DOWN/HOLD thresholds: UP if return > +2.00%; DOWN if return < -2.00%; otherwise HOLD.
Thresholds are explicit initial modelling assumptions, not externally authenticated financial standards. Tune using training/validation only.
