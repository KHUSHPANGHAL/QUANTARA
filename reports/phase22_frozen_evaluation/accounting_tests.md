### 1. Standardization of Return Accounting

To eliminate ambiguity across all future phases, returns are strictly computed relative to initial capital:

$$\text{Standard Return (\%)} = \left(\frac{E_{\text{Final}} - \text{₹1,00,000.00}}{\text{₹1,00,000.00}}\right) \times 100\%$$

#### Reconciliation with Legacy Formula:
In Phases 14 through 20, the evaluation function `compute_metrics` divided by Day 1 end-of-day equity:
$$\text{Legacy Return (\%)} = \left(\frac{E_{\text{Final}} - E_{\text{Day 1 EOD}}}{E_{\text{Day 1 EOD}}}\right) \times 100\%$$
Because cash interest accrued on session 0 ($E_{\text{Day 1 EOD}} = \text{₹100,020.12}$), legacy returns were compressed by an offset of approximately $-0.02\%$ across all interest-bearing strategies. Both metrics are reported side-by-side in Phase 22 deliverables.

---

### 2. Conservation of Capital Equation

At every session and at portfolio liquidation, total portfolio value must reconcile with zero residual:
$$E_{\text{Final}} = E_{\text{Starting}} + \sum_{j=1}^{N} \text{NetPnL}_j + \text{Interest}_{\text{accrued}}$$
where:
- $\text{NetPnL}_j = \text{Gross Proceeds} - \text{Sell Fee} - \text{Cost Basis} + \text{Dividends Credited}$
- $\text{Cost Basis} = \text{Shares} \times P_{\text{entry}} + \text{Buy Fee}$
- $\text{Accounting Residual} = \left|E_{\text{Starting}} + \sum \text{NetPnL} + \text{Interest} - E_{\text{Final}}\right|$
